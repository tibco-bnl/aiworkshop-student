# Workstation VS Code setup

In the workstation desktop VS code is installed including the Flogo vscode extension.
Click (one time) on the blue vscode icon on the launch pad.

To check the extensions installed click on the extension<br> ![alt text](/student/images/vscode_extensionicon.png)
